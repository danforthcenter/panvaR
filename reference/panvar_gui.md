# panvar_gui Run the panvaR shiny implementation. Will launch in a default browser or can navigate to IP address shown.

panvar_gui Run the panvaR shiny implementation. Will launch in a default
browser or can navigate to IP address shown.

## Usage

``` r
panvar_gui(display.mode = "auto", launch.browser = TRUE, ...)
```

## Arguments

- display.mode:

  display mode of shiny app, see documentation for
  [`shiny::runApp()`](https://rdrr.io/pkg/shiny/man/runApp.html)

- launch.browser:

  should browser be launched automatically or not

- ...:

  arguments passed to
  [`shiny::runApp()`](https://rdrr.io/pkg/shiny/man/runApp.html)
